## 🚀 Next Step: Generate Code with PDD

### Quick Start Command

```bash

pdd --local --force sync foreman_cli --target-coverage 80
```

## 📊 Prompt File Quality Checklist

Each prompt file includes:

✅ **GOAL** - Clear objective
✅ **CONTEXT** - Why this component exists
✅ **STACK** - Technologies used
✅ **ARTIFACTS** - Files to generate
✅ **FUNCTIONAL_REQUIREMENTS** - What it must do
✅ **NON_FUNCTIONAL_REQUIREMENTS** - How it must perform
✅ **INTERFACE** - Type signatures and APIs
✅ **TESTS** - What to test
✅ **VERIFICATION** - Success criteria
✅ **NOTES** - Important implementation details

2. PDD generates code + tests
3. PDD ensures 80% coverage
4. Iterate with `pdd fix` if needed

## 🔄 Workflow After Generation

1. **Generate code:** Run PDD on each prompt
2. **Review:** Check generated code
3. **Fix issues:** Use `pdd fix` if tests fail
4. **Build:** `pnpm build` in packages/foreman
5. **Initialize Convex:** `npx convex dev` in apps/api
6. **Set up env vars:** Copy `.env.example` to `.env`
7. **Test:** Run `pnpm -r test`
8. **Run:** `./foreman.sh demo_todo`

## 💡 Tips for Success

1. **Generate in order** - Some components depend on others
2. **Check each result** - PDD isn't perfect, review the code
3. **Use `pdd fix`** - If tests fail, this often resolves it
4. **Budget wisely** - Set `--budget` flags to control costs
5. **Commit often** - Save your progress after each successful generation
6. **Test incrementally** - Don't wait until everything is generated

## 🆘 If Something Goes Wrong

**PDD can't find prompt:**
- Check you're in the right directory
- Ensure `PDD_PATH` is set
- Verify filename ends with `_typescript.prompt`

**Generated code has errors:**
- Run `pdd --local fix <basename>`
- Check the prompt file for clarity
- Try regenerating with `--force`

**Tests failing:**
- This is normal! Use `pdd fix`
- May need 2-3 fix iterations
- Check test output for clues

**Costs too high:**
- Use `--budget` flag
- Start with simpler prompts
- Consider reducing coverage target
